1. Temporal Difference Learning

GPI: Generalized Policy Iteration

\[PE \rightarrow PI \rightarrow PE \rightarrow PI \rightarrow \cdots\]

  • 강화 학습의 학습 루프는 Policy Evaluation과 Policy Improvement의 반복이다.

Policy Evaluation 방법에는 Monte Carlo(MC)와 Temporal Difference(TD)가 있다.

Model Backup Algorithm
Monte Carlo Full Backup \(V(S_{t}) \gets V(S_{t}) + \alpha [G_{t} - V(s_{t})]\)
Temporal Difference One-Step Backup \(V(S_{t}) \gets V(S_{t}) + \alpha [R_{t+1} + \gamma V(s_{t+1}) - V(s_{t})]\)
  • TD target: \(R_{t+1} + \gamma V(s_{t+1})\)
  • TD error: \(\delta_{t} = \text{TD target} - V(s_{t}) = R_{t+1} + \gamma V(s_{t+1}) - V(s_{t})\)
  • Sampling + Bootstrapping

On-policy TD prediction: SARSA \[Q(S_{t}, A_{t}) \gets Q(S_{t}, A_{t}) + \alpha [R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_{t}, A_{t})]\]

  • 안전한 경로

Off-policy TD prediction: Q-learning \[Q(S_{t}, A_{t}) \gets Q(S_{t}, A_{t}) + \alpha [R_{t+1} + \gamma \max_{a} Q(S_{t+1}, a) - Q(S_{t}, A_{t})]\]

  • Optimistic한 경로

On-policy vs Off-policy

  • On-policy: Target policy \(\pi\) = Behavior policy \(\mu\)
  • Off-policy: Target policy \(\pi\) \(\neq\) Behavior policy \(\mu\)

Importance Sampling

\[\mathbb{E}_{x\sim p}[f(x)] = \int f(x) p(x) dx = \int f(x) \frac{p(x)}{q(x)} q(x) dx = \mathbb{E}_{x\sim q} \left[ f(x) \frac{p(x)}{q(x)} \right]\]

In RL: \(\rho_{t} = \frac{\pi(a_{t}|s_{t})}{\mu(a_{t}|s_{t})}\)

Variance 폭발 문제 \(\rightarrow\) Weighted IS로 해결 \[\frac{1}{\sum_{i=1}^{N} \rho_{i}}\sum_{i=1}^{N} \rho_{i} G_{i}\]

약간의 Bias 도입, Variance 대폭 감소.

Off-policy MC

\[G_{t}^{\pi/\mu} = \rho_{t}^{T} G_{t} = \prod_{k=t}^{T-1} \frac{\pi(a_k|s_k)}{\mu(a_k|s_k)} G_{t}\]

  • Product 계산이 되므로 step이 커질수록 variance가 커질 수 있다. 이를 보완하기 위해 Weighted IS를 사용한다.

Off-policy TD

\[\rho_{t} = \frac{\pi(a_{t}|s_{t})}{\mu(a_{t}|s_{t})}\]

  • TD는 한 스텝만 사용하므로 IS도 한 번만 적용한다. 따라서 MC보다 variance가 훨씬 작다.

Advanced TD Methods

Expected SARSA

\[Q(S_{t}, A_{t}) \gets Q(S_{t}, A_{t}) + \alpha [R_{t+1} + \gamma \mathbb{E}_{a} [Q(S_{t+1}, a)] - Q(S_{t}, A_{t})]\]

  • \(Q\)에 대한 expected value를 사용하여 TD target 계산 → Variance 감소

Double Q-learning

Maximization Operation의 Overestimation 문제 해결을 위해 행동 선택과 가치 평가를 분리한다.

With 0.5 probability, update either \(Q_1\) or \(Q_2\):

  • \(Q_{1}(S,A) \gets Q_{1}(S,A) + \alpha \left[R + \gamma Q_{2}(S', \arg\max\limits_{a} Q_{1}(S', a)) - Q_{1}(S,A)\right]\)
  • \(Q_{2}(S,A) \gets Q_{2}(S,A) + \alpha \left[R + \gamma Q_{1}(S', \arg\max\limits_{a} Q_{2}(S', a)) - Q_{2}(S,A)\right]\)

TD(\(\lambda\))

\(G_{t}^{(1)} = R_{t+1} + \gamma V(S_{t+1})\) : One-step TD target

\(G_{t}^{(2)} = R_{t+1} + \gamma R_{t+2} + \gamma^{2} V(S_{t+2})\)

\(\vdots\)

\(G_{t}^{(n)} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^{n} V(S_{t+n})\)

\(G_{t}^{\infty} = R_{t+1} + \gamma R_{t+2} + \cdots\) : Monte Carlo target

  • \(\lambda\)-return: \(G_{t}^{\lambda} = (1-\lambda) \sum_{n=1}^{\infty} \lambda^{n-1} G_{t}^{(n)}\)
  • \(\lambda \in [0, 1]\)이다.

TD(\(\lambda\)): \(V(S_{t}) \gets V(S_{t}) + \alpha [G_{t}^{\lambda} - V(S_{t})]\)

  • \(\gamma\): 얼마나 먼 미래의 reward도 중요하게 생각할 것인가
  • \(\lambda\): 얼마나 return을 믿고(1), 얼마나 TD target을 믿을 것인가(0)

2. Deep Q-Networks

  • RL의 경우 Bellman equation을 이용해 Tabular update를 한다.
    • MC, SARSA, Q-learning
  • DRL의 경우 function approximation을 이용해 update한다.
    • Value function \(Q(s,a)\): DQN
    • Policy \(\pi(a|s)\): Policy Gradient, REINFORCE
    • Value function + Policy: Actor-Critic

Law of Effect

  • 행동의 결과가 좋으면 그 행동을 더 자주 하게 된다.
  • 행동의 결과가 나쁘면 그 행동을 덜 하게 된다.

Deep Q-Networks (DQN)

CNN을 사용한 Q-learning 모델.

Large or Continuous State Space \(\rightarrow\) Discrete Action Space

Naive DQN

\[L(\theta) = \left[r_{t+1} + \gamma \max\limits_{a} Q(s_{t+1}, a; \theta) - Q(s_t, a_t; \theta)\right]^2\]

Q-learning의 TD target을 이용하여 DNN을 학습한다.

문제점
  • Temporal Correlation: SGD는 독립 샘플을 가정하지만, RL 데이터는 서로 강한 상관 관계가 있어 학습이 불안정하다.
  • Non-stationary Target: Target과 Behavior가 같은 네트워크로 계산되므로, Target이 계속 변화하여 학습이 불안정하다.
해결책
  • Experience Replay: Buffer에 넣고 무작위로 샘플링, 거의 i.i.d.
  • Target Network: Behavior Network만 업데이트하고, 일정 주기로 Target Network의 가중치를 Behavior Network에서 복사하여 Target이 천천히 변화하도록 한다. \[L(\theta) = \frac{1}{B}\sum_{|i|=B}\left[r_{i+1} + \gamma \max\limits_{a} \hat{Q}(s_{i+1}, a; \hat{\theta}) - Q(s_i, a_i; \theta)\right]^2\]
  • Reward Clipping: 게임마다 다른 reward scale을 \(\begin{cases}1&r>0\\-1&r<0\end{cases}\) 로 제한하여 학습 안정성 향상

CNN in DQN

4 frame의 이미지를 state로 넣으면 입력 차원이 너무 커지므로, CNN을 이용해 256차원으로 압축한다.

작은 데이터도 중요하기 때문에 Max pooling은 사용하지 않는다.

Multi-step Learning

n-step return을 사용할 수도 있다.

\[r_{t+1}^{n} = \sum_{k=0}^{n-1} \gamma^{k}r_{t+k+1}\]

DQN의 loss를 n-step return으로 변경한다.

\[L(\theta) = \left[r_{t+1}^{n} + \gamma \max\limits_a\hat{Q}\left(S_{t+n},a;\hat{\theta}\right) - Q(S_{t}, a_{t};\theta)\right]^2\]

Double DQN

DQN은 자기가 고른 행동을 자기가 평가해 overestimate를 한다.
이 문제를 해결하기 위해 Behavior Network와 Target Network를 분리한다. 또한 Double Q-learning 방식을 차용한다.

\[L(\theta) = \left[r_{t+1} + \gamma\hat{Q}\left(S_{t+1},\arg\max Q(S_{t+1},a;\theta);\hat{\theta}\right) - Q(S_{t}, a_{t};\theta)\right]^2\]

선택은 Behavior Network가, 평가는 Target Network가 한다.
이 때 Target Network는 DQN과 마찬가지로 Behavior Network에서 복사한 것이다.

Prioritized Replay

DQN의 Experience Replay: 경험을 균등하게 뽑는다.

\[P(i)=\frac{1}{N}\]

TD error가 큰 데이터는 현재 네트워크가 많이 틀렸다는 뜻이므로 더 자주 뽑게 한다.

\[P(i) = \frac{p_{i}^{\alpha}}{\sum_{k} p_{i}^{k}}\ \text{where}\ p_{i} = |r_{i+1} + \gamma \max\limits_a\hat{Q}(s_{i+1},a;\hat{\theta}) - Q(s_{i}, a_{i}; \theta)| + \epsilon\]

많이 틀린 문제를 더 자주 보기 때문에 sampling 분포가 바뀐다. 따라서 이 bias를 보정하기 위해 Importance Sampling Weights를 사용한다.

  • \(w_{i} = \left(\frac{1}{N}\cdot\frac{1}{P(i)}\right)^{\beta}\)
    • \(\beta=1\): 완전한 importance sampling
    • \(\beta=0\): 보정 없음

Q-learning Update에서는 TD error \(\delta_{i}\) 대신 \(w_{i}\delta{i}\)를 사용했다.
이 때 \(w_{i}\)가 커져서 gradient가 폭발할 수 있기 때문에 보정항 \(\frac{1}{\max_{k}w_{k}}\)를 곱한다. 이로 인해 \(w_{i}\in[0,1]\)이 된다.

Dueling DQN

CNN encoder를 공유하는 2개의 stream으로 나눈다.
\(Q=V+A\)를 만족하는 해는 무수히 많다(Identifiability Issue).
Advantage의 평균을 \(0\)으로 강제해 해를 유일하게 정하도록 한다.

\[Q(s,a) = V(s) + \left(A(s,a) - \frac{1}{|A|}\sum_{a'}A(s',a)\right)\]
